# v1.0 step 1: Inbox — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every job that messages the owner writes an `inbox` row first; Telegram becomes one renderer of those rows; weekly ideas wait for
Keep or Drop before reaching Plane.

**Architecture:** a new `IInbox` service stores an `InboxEntry` (idempotent on a key) and, only while `Telegram:Token` is set, sends the job's
existing `OutMessage` through `TelegramClient` and returns the message id. Seven call sites swap `telegram.SendAsync` for `inbox.AddAsync`.
Jobs run when Telegram **or** swipe mode can deliver.

**Tech stack:** .NET 10, Dapper + Npgsql, xUnit, Testcontainers Postgres (`PostgresFixture`), `StubHandler` for Telegram.

**Spec:** `docs/specs/2026-10-19-v1.0-app.md` (section Server 1). Master plan: `docs/plans/2026-10-19-v1.0-app.md`.

## Global constraints
- With `Telegram:Token` set, every Telegram message keeps its text and buttons, except the weekly ideas message, which gains Keep/Drop.
- With `Telegram:Token` empty, no job fails and none deletes or marks failed the state it made (follows keep running, duels are not marked failed).
- `inbox.key` makes `AddAsync` idempotent: a job that retries after a failed send gets the same row and sends again.
- Migration `0029_inbox.sql`; add `inbox` to `PostgresFixture.ResetAsync`.
- Run `dotnet test FeedEater.slnx` and `dotnet format --verify-no-changes` before each commit.

## Review focus
1. **Telegram send fails after the row is written.** Row kept, exception rethrown, job state unchanged from today (duel marked failed, follow root rollback). Test in Task 1 and Task 3.
2. **Same job runs twice for one key** (retry after a crash): one inbox row, message sent twice as today. Test in Task 1.
3. **Telegram off, follow started from the app later:** `StartAsync` must not delete the follow because the root message cannot be sent. Test in Task 3.
4. **Keep pressed twice, or Keep after Drop:** one Plane item at most; the second press answers "Already decided". Test in Task 6.
5. **Ideas for a week where Plane is down at Keep time:** the entry stays open and Keep can be pressed again; no `weekly_ideas` row until Plane answers. Test in Task 6.

```sql
-- v1.0 inbox (docs/specs/2026-10-19-v1.0-app.md): what used to be only a Telegram message. Telegram renders it while its token is set; swipe sessions queue it.
create table inbox (
    id            bigserial primary key,
    key           text not null unique,                      -- what makes a retried job write one row: 'duel:12', 'review:2026-10-18'
    kind          text not null check (kind in ('follow', 'duel', 'release', 'idea', 'review', 'autopsy', 'resurface', 'notice')),
    item_id       bigint references items (id),
    ref_id        bigint,                                    -- the duel, follow or other row the entry is about
    payload       jsonb not null default '{}',
    created_at    timestamptz not null default now(),
    expires_at    timestamptz,
    shown_session bigint references swipe_sessions (id) on delete set null,
    done_at       timestamptz
);
create index inbox_open_idx on inbox (created_at) where done_at is null;

-- Ideas wait for Keep or Drop; a dropped idea is remembered so the shortlist does not offer its source again.
alter table weekly_ideas
    add column outcome text not null default 'filed' check (outcome in ('filed', 'dropped')),
    alter column plane_issue_id drop not null;
```

```csharp
using System.Text.Json.Nodes;
using Dapper;
using FeedEater.Inbox;

namespace FeedEater.Storage;

public sealed class InboxStore(FeedDb db)
{
    private const string Columns = "id, key, kind, item_id, ref_id, payload::text as payload, created_at, expires_at, shown_session, done_at";

    /// <summary>Returns the existing row's id when the key was written before.</summary>
    public async Task<long> AddAsync(InboxEntry e, DateTimeOffset now, CancellationToken ct)
    {
        await using var c = await db.DataSource.OpenConnectionAsync(ct);
        return await c.ExecuteScalarAsync<long>(new CommandDefinition(
            """
            insert into inbox (key, kind, item_id, ref_id, payload, created_at, expires_at)
            values (@Key, @Kind, @ItemId, @RefId, @Payload::jsonb, @Now, @ExpiresAt)
            on conflict (key) do update set key = excluded.key
            returning id
            """,
            new { e.Key, e.Kind, e.ItemId, e.RefId, Payload = (e.Payload ?? []).ToJsonString(), Now = now.UtcDateTime, ExpiresAt = e.ExpiresAt?.UtcDateTime },
            cancellationToken: ct));
    }

    public async Task<InboxRow?> GetAsync(long id, CancellationToken ct)
    {
        await using var c = await db.DataSource.OpenConnectionAsync(ct);
        var raw = await c.QuerySingleOrDefaultAsync<Raw>(new CommandDefinition($"select {Columns} from inbox where id = @id", new { id }, cancellationToken: ct));
        return raw?.ToRow();
    }

    /// <summary>Not done, not expired, oldest first.</summary>
    public async Task<IReadOnlyList<InboxRow>> OpenAsync(DateTimeOffset now, int limit, CancellationToken ct)
    {
        await using var c = await db.DataSource.OpenConnectionAsync(ct);
        return (await c.QueryAsync<Raw>(new CommandDefinition(
            $"select {Columns} from inbox where done_at is null and (expires_at is null or expires_at > @now) order by created_at, id limit @limit",
            new { now = now.UtcDateTime, limit }, cancellationToken: ct))).Select(r => r.ToRow()).ToList();
    }

    /// <summary>False when it was already done.</summary>
    public async Task<bool> DoneAsync(long id, DateTimeOffset at, CancellationToken ct)
    {
        await using var c = await db.DataSource.OpenConnectionAsync(ct);
        return await c.ExecuteAsync(new CommandDefinition(
            "update inbox set done_at = @at where id = @id and done_at is null", new { id, at = at.UtcDateTime }, cancellationToken: ct)) == 1;
    }

    private sealed record Raw(long Id, string Key, string Kind, long? ItemId, long? RefId, string Payload, DateTime CreatedAt, DateTime? ExpiresAt,
        long? ShownSession, DateTime? DoneAt)
    {
        public InboxRow ToRow() => new(Id, Key, Kind, ItemId, RefId, JsonNode.Parse(Payload)!.AsObject(), Utc(CreatedAt), ExpiresAt is { } e ? Utc(e) : null,
            ShownSession, DoneAt is { } d ? Utc(d) : null);

        private static DateTimeOffset Utc(DateTime t) => new(DateTime.SpecifyKind(t, DateTimeKind.Utc));
    }
}
```

```csharp
using Microsoft.Extensions.Options;
using FeedEater.Storage;
using FeedEater.Telegram;

namespace FeedEater.Inbox;

public sealed class InboxService(InboxStore store, TelegramClient telegram, IOptions<FeedEaterOptions> options, TimeProvider? time = null) : IInbox
{
    public async Task<InboxPost> AddAsync(InboxEntry entry, OutMessage message, CancellationToken ct, long? replyToMessageId = null)
    {
        var id = await store.AddAsync(entry, (time ?? TimeProvider.System).GetUtcNow(), ct);
        var o = options.Value.Telegram;
        if (o.Token.Length == 0)
        {
            return new InboxPost(id, null);
        }

        return new InboxPost(id, await telegram.SendAsync(o.AllowedUserId, message, ct, replyToMessageId));
    }
}
```

```csharp
using FeedEater.Inbox;
using FeedEater.Plane;
using FeedEater.Storage;

namespace FeedEater.WeeklyIdeas;

public enum IdeaOutcome { Filed, Dropped, AlreadyDecided, NotFound, Failed }

public sealed record IdeaDecision(IdeaOutcome Outcome, string? Project = null, string? Error = null);

/// <summary>Keep files a staged idea in Plane Intake; Drop remembers its source. The inbox row's done_at is the decision, so a second press changes nothing.</summary>
public sealed class IdeaDecisions(InboxStore inbox, WeeklyIdeaStore ideas, PlaneClient plane, TimeProvider time)
{
    public async Task<IdeaDecision> KeepAsync(long inboxId, CancellationToken ct)
    {
        if (await OpenIdeaAsync(inboxId, ct) is not { } row)
        {
            return await inbox.GetAsync(inboxId, ct) is null ? new(IdeaOutcome.NotFound) : new(IdeaOutcome.AlreadyDecided);
        }

        var p = row.Payload;
        string issue;
        try
        {
            issue = await plane.CreateIntakeAsync(Str(p, "project"), Str(p, "title"), Str(p, "html"), ct);
        }
        catch (Exception ex) when (ex is HttpRequestException or InvalidOperationException)
        {
            return new(IdeaOutcome.Failed, Error: ex.Message);
        }

        if (!await inbox.DoneAsync(inboxId, time.GetUtcNow(), ct))
        {
            return new(IdeaOutcome.AlreadyDecided);   // a concurrent press won; its Plane item stands
        }

        await ideas.AddAsync(new FiledIdea(Str(p, "url"), Str(p, "week"), Str(p, "title"), Str(p, "project"), issue), ct);
        return new(IdeaOutcome.Filed, Str(p, "project"));
    }

    public async Task<IdeaDecision> DropAsync(long inboxId, CancellationToken ct)
    {
        if (await OpenIdeaAsync(inboxId, ct) is not { } row || !await inbox.DoneAsync(inboxId, time.GetUtcNow(), ct))
        {
            return await inbox.GetAsync(inboxId, ct) is null ? new(IdeaOutcome.NotFound) : new(IdeaOutcome.AlreadyDecided);
        }

        var p = row.Payload;
        await ideas.DropAsync(Str(p, "url"), Str(p, "week"), Str(p, "title"), Str(p, "project"), ct);
        return new(IdeaOutcome.Dropped);
    }

    private async Task<InboxRow?> OpenIdeaAsync(long id, CancellationToken ct) =>
        await inbox.GetAsync(id, ct) is { Kind: InboxKinds.Idea, DoneAt: null } row ? row : null;

    private static string Str(System.Text.Json.Nodes.JsonObject p, string key) => p[key]?.GetValue<string>() ?? "";
}
```
